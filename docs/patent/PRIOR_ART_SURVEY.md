# 同类专利 / 材料调研（背景与创造性引证用）

> 用途：交底书 §三 背景技术"最接近现有技术"与 §创造性定位的素材；**非完整 FTO 检索**，
> 仅检索摘要层，代理人在撰写/审查阶段需做正式检索。
> 检索日期：2026-09-02。

## 一、结论（先给定位）

1. **“载重影响能耗/航程”这一认知本身不构成新颖性**：多篇 CN 专利已把无人机载重-能耗/航程建模为
   线性关系并纳入约束或目标。
2. 同类专利多为 **显式 MILP/MINLP + 元启发式**（GA / ALNS / 改进麻雀 / 人工蜂群），
   面向多机/车-机协同/时间窗等复杂场景，求解重、规模较大。
3. 我们（潜在区别特征）的组合是：
   - 把**状态相关能耗折进“等效电量距离”**，使**经典固定矩阵启发式**（NN/Savings/2-opt/Or-opt）可直接运行；
   - 对每条候选移动做**增量可行性（容量+电量）校验**（O(k) 增量电量校验）；
   - 单机小规模（n≤20）、确定性、毫秒级，面向嵌入式/指挥中心在线重算场景。
4. **撰写口径**：背景缺陷写“目标函数不含状态相关能耗 + 可行性事后校验 → 最优解在真实模型下不可行”，
   不宣称“载重耦合从未被建模”。创造性表述围绕“变换-经典启发式复用-增量校验”的整体方案及其轻量/确定优势。

### 能耗-载重变化驱动的顺序/调度类（说明“顺序影响能耗”前案多）
- “基于遗传算法的无人机车辆协同配送路径优化”（MINLP，目标=总能耗等加权和，明确针对“因载重变化导致的能耗”）；
- CN114331280B 客户满意度+能量优化：按分区 TSP 顺序与最小能耗划分边界 → 顺序×能耗已被重视；
- IBM US20190187695：早投递更轻更省，可用于多机间能量分配。

## 三、对我们撰写/答辩的影响

- 独权要素建议落在（供代理人参考）：
  “接收目标点/仓库/机型参数 → **构造与载重相关的等效电量距离** → 基于该距离进行电量感知访问顺序构造 →
  **局部搜索中对移动做增量电量与载重校验** → 后验证输出可行序列”。
- §三 缺陷叙述围绕“目标与可行性解耦”；§五/§六 强调“变换+经典启发式+增量校验”整体带来的
  **轻量、确定、毫秒级、不依赖重型求解器**，与上述前案的“元启发式重求解”形成对照。
