## 图1 fig1_overview — 方法总体流程（S1–S6，含模式选择）

**图注**：本发明方法的总体流程。输入为目标点集合（坐标、需求量）、仓库位置与无人机参数
（α、β、载重上限、电池容量）；S1 构建载重感知等效电量距离（逐段按出发载重求值）；
S2 电量感知最近邻构造（N 起点），
含载重预检与往返电量可行性判断；S3 增量局部搜索（2-opt 与 Or-opt 交替），每次候选移动做
仅按受影响段做增量电量校验（载重上限由构造前的总需求预检保证）；
**S5 模式选择**：按目标点数估算精确模式的耗时与峰值内存，与时限/内存预算比较后分岔——
**预算足**则走 **S4 精确求解模式**（分层状态推进 + 批量转移 + 可采纳下界剪枝），
**预算不足**则直接采用 S3 的启发式解（降级模式）；两路汇入 S6 逐段全量后验证；
输出访问顺序、总等效电量距离与可行性。

**图描述**：自上而下为输入框、S1–S3、S5（决策框）、S4 与降级两个并列分支、S6 与输出框。
S2 构造不可行时直接返回部分路线并置 feasible=false，不进入搜索
（该分支说明见正文，图内不画出）；S3 直至无改进或达迭代上限。
步序即权利要求的方法步骤顺序；两个分支的取舍由 S5 依预算决定（详见图10）。

## 图2 fig2_energy_rate — 单位距离能耗率模型

**图注**：标准机型（α=0.1 Wh/m，β=0.005 Wh/(m·kg)，载重上限 50 kg）的单位距离能耗率
ρ(L)=α+βL 随出发载重 L 线性增长：纵截距为 α（空载能耗率），斜率为 β（载重敏感系数）。

**图描述**：横轴出发载重 L（0–50 kg），纵轴能耗率 ρ（Wh/m）。直线在中上部转折处的含义由
“截距 α / 斜率 β”标注说明。说明要点：同一段几何距离，出发载重越大能耗越高——这是访问顺序
影响总能耗的根源。**注**：三种机型的 α/β/载重上限差异见 §八 机型参数表，不在本图并列
（light 5 kg / standard 50 kg / heavy 500 kg 同轴不可比）。

## 图3 fig3_equiv_dist — 等效电量距离（代价表达，非区别特征）

**图注**：等效电量距离定义 EED(i,j,L)=d_ij·(α+βL)/α=d_ij(1+βL/α)。同一几何边在满载出发时
等效电量距离更长；空载出发时退化为几何距离 d_ij。

**图描述**：两条水平距离条与一条几何距离基准虚线。说明：把状态相关的能耗折进“距离标度”后，
构造与搜索算子可在**同一量纲**下统一处理代价与可行性判断。
**注意**：EED 是 (i,j,L) 的三元函数而非固定矩阵（L 由未访问点集决定），故经典距离型算子
**仍需按当前载重逐段求值**；且 EED 与能耗仅差常数因子 α，**不改变优化问题的解**——
本图仅为代价表达的统一，非区别技术特征。与图2 的关系：图2 是“速率”视角，
图3 是“距离”视角，同一公式的两种用法。

## 图4 fig4_order_effect — 访问顺序影响能耗（实例）

**图注**：8 点实例（随机分布，seed=2，标准机型，总需求 45.8 kg）两种访问方向对比：（a）几何最优
TSP 环的一个方向，（b）反向访问（本方法解，与能量精确动态规划最优一致）。两方向**总几何距离
相同（3962.2 m）**，但因载重-能耗耦合，**总能耗由 872.7 Wh 降至 827.1 Wh（省 5.2%）**。
（省电百分比口径与主表 `Gap_eng%` 一致：以基线几何最优路线为分母。）

**图描述**：同一 8 点哈密顿环画成左右两面板，节点用数字 1–8 标记、仓库为方块（“仓库”）。
箭头方向表示行进方向（(a) 实线、(b) 虚线）。两面板图形重合、方向相反，直观说明：
**纯几何优化无法区分这两个方向**，只有把载重-能耗耦合纳入目标才能选出更省电的顺序。
数据与逐段载重/能耗见 `scripts/fig4_data.json`（§八 走通实例）。

## 图5 fig5_two_opt — 2-opt 翻转与受影响段（实施细节）

**图注**：2-opt 翻转一段子路径：翻转前 …a–b–c–d–e…，翻转后 …a–d–c–b–e…。
线型含义：细灰=翻转前后不变的前缀/后缀；虚线=被翻转子段 b–c–d 的内部；粗实=重新连接的两条边。

**图描述**：上排“翻转前”、下排“翻转后”。受影响范围仅为：两条重连边（a–d、b–e）与子段内部
（其出发载重改变、且需保证段内电量不为负）；前缀（仓库…a）与后缀（e…仓库）的载重与电量不变。
**注意**：由于评估候选移动时仍需沿前缀推演一次当前剩余电量与载重，单次评估实际为 O(i+|S|)，
该"只算受影响段"的限定**不降低渐近阶数**，其收益为常数因子（实测约 3.0 倍）；增量代价评估
属本领域已知技术（见交底书 5.4、5.8 节），非区别技术特征。

## 图10 fig10_architecture — 自适应分级求解架构（模式选择与两模式协同）

**图注**：自适应分级求解架构。输入为目标点集合、仓库位置与无人机参数；随后：
（i）**启发式求解（降级模式）**——电量感知最近邻构造 + 增量局部搜索（2-opt/Or-opt），
产出一个可行解（候选降级解）；（ii）**资源预算评估**——按目标点数 n 估算精确模式的
耗时与峰值内存，与时限/内存预算比较；（iii）**模式判定**——预算满足则走**精确模式**
（分层状态推进 + 批量转移 + 可采纳下界剪枝，产出最优序列），否则走**降级模式**
（直接采用启发式解，产出可行序列）；（iv）两路汇入**后验证**；
输出访问顺序、总等效电量距离、总能耗与可行性标记（含模式标注）。

**图描述**：自上而下为输入框、启发式求解框、资源预算评估框、模式判定框、
两个并列分支（精确模式 / 降级模式）、后验证与输出框。
左侧的**虚线箭头**标注两模式的协同：启发式解作为**剪枝上界 UB** 传入精确模式
（上界越紧、剪枝越强），故两模式为协同关系而非彼此替代。
对应 `a3_python/adaptive.py::plan_multistop_adaptive` 的实现流程。
