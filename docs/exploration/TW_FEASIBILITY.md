# 探索：时间窗 + 悬停耗电的可行性验证（V1–V3）

> **性质**：探索性验证（exploration），**不属于 MVP 交付**，产物不并入主干直至结论通过。
> 分支 `worktree-tw-feasibility`，工作区 `.claude/worktrees/tw-feasibility`。
> 目的：验证"引入时间窗与悬停耗电后，能否产生一个非等价改写的新机制"。

## 1. 为什么做这件事

当前 MVP 的三个声称创新点经审查模拟后均不成立：

| 声称创新点 | 判定 | 依据 |
|---|---|---|
| ① 等效电量距离变换 | **数学等价改写**，无技术效果 | $\mathrm{EED}=E/\alpha$；实测两方案几何距离相同时 α 项贡献差 = 0.0000 Wh |
| ② 载重-能耗耦合模型 $\rho=\alpha+\beta L$ | **领域常识** | 本项目自引文献（Dorling 等）已公开该线性关系 |
| ③ 增量电量校验 | 非首创且未兑现 | ALNS 类方法常规做法；实测为 $O(i+|S|)$，阶数未降 |

根因：**MVP 边界（单机 + n≤20 + 线性模型 + 无时间窗 + 静态）把问题削得过简**。
本探索通过**扩大边界**来验证能否恢复新颖性。

**核心假设（待验证）**：
引入时间窗后，"早到需悬停"会引入一个**与位移距离无关的能耗项**，
使总能耗不再能表示为"某个距离标度 × 常数"，
从而 $\mathrm{EED}$ 变换**在数学上失效**，迫使方案必须处理"时间-电量-载重"三方耦合。
若该耦合存在且必须专门处理，则可能构成真正的技术贡献；若只是"加一个约束检查"，
则本探索**判定失败**，项目退回诚实交付定位（不主张专利创新性）。

## 4. 时间窗与悬停耗电的建模（V1 规格）

沿用 Solomon 原始数据字段：目标点 $i$ 有服务时间窗 $[e_i, l_i]$ 与服务时长 $s_i$。

- 到达时刻 $t_i^{arr}$；实际开始服务时刻 $t_i^{start}=\max(t_i^{arr}, e_i)$；
  若 $t_i^{arr} > l_i$ 则该序列不可行。
- 离开时刻 $t_i^{dep}=t_i^{start}+s_i$；段 $i\to j$ 飞行时间 $\Delta t = d_{ij}/v$（$v$ 为巡航速度）。
- **悬停耗电**：早到等待 $w_i = \max(0, e_i - t_i^{arr})$，悬停功率 $P_{hov}$（常量，Wh/s），
  则该点等待耗电 $= P_{hov}\cdot w_i$，**不产生任何位移**。
- 总能耗 $= \underbrace{\Sigma\, d_k(\alpha+\beta L_k)}_{\text{位移项}} + \underbrace{P_{hov}\Sigma w_i}_{\text{悬停项}}$。

**关键性质（V3 的核心检验对象）**：
位移项仍可写成 $\alpha\cdot\Sigma \mathrm{EED}_k$，但悬停项**与距离无关**，
故总能耗 **不能**表示为"某个距离标度 × 常数 α"，$\mathrm{EED}$ 变换失去完备性。

## 5. 结论（V3 完成）

> 详细数据见 `TW_RESULTS.md`；Q3 的否定性论证见 `TW_MECHANISM.md`。

### 一句话结论

**核心假设被证实为一"事实"，但没有产生可专利的新机制 ⇒ 本探索判定失败。**

引入时间窗后，"早到需悬停"确实引入了一个与位移距离无关的能耗项，
EED 变换确实不再是总能耗的充分统计量 —— 但补救它所需的全部手段都是
已公开数十年的教科书技术（VRPTW 前向时间递推、前向时间松弛、目标函数含等待能耗）。
项目应**退回诚实交付定位，不主张专利创新性**。

### Q1. 等效电量距离是否失效？

**部分失效 —— 位移项仍精确，但总能耗不能再写成"距离标度 × 常数"。**

- 恒等式 `total = α·ΣEED + P_hov·Σw` 精确成立（实测残差 ≤ **0.0064 Wh**，纯取整误差）。
- 悬停占比实测 **1.9% ~ 76.6%（均值 24.1%）**；C101 可行子集上高达 **76.6%**，即能耗被距离无关项主导。
- 判据"隐含标度"α_eff = total/ΣEED：**α_eff/α = 1.019 ~ 4.266，极差 3.25 倍** ——
  不存在任何单一常数，EED 变换**丧失完备性**。
- 后果：以 ΣEED 最小化为搜索目标 **不等价** 于总能耗最小（见 Q3，57% 实例落到不同路线）。

### Q2. 增量校验的受影响范围是否被破坏？（最关键一问）

**是，被双重破坏。O(k) 增量校验在时间窗下不成立。**

1. **"必须计算"的范围 = O(n−f)，不是 O(k)**：出发时刻改变会顺延其后**所有**点
   的到达时刻。实测 `compute_len` 恒 ≥ `moved_len`，n=18 时平均 11.3 vs 6.6。
   逐点证据：一次 2-opt 中时刻偏移 **+5.56 s 原样传到返航段**，`time_span = 8 = compute_len` 而 `moved_len = 3`。
2. **"真正变化"的范围也超出 O(k)**：全局 1125 个候选移动，`obs/moved` 均值 **1.74**、
   最大 **8.00**（随 n 从 1.14 增长到 2.02）；`time/moved` = 1.27 ~ 1.70。
3. **判决性对照**：置 `hover_power = 0`（无悬停耗电、时间窗仍在），传播范围**逐格完全相同**。
   ⇒ 失效根因是**时刻闭包**，与新增的悬停耗电项无关。**早在 MVP 阶段，只要引入时间窗，O(k) 就已失效。**
4. 全序列恒早到（等待到处存在）时仍有 90~100% 的候选移动把影响传播到末尾 ⇒
   等待只能**部分**吸收时刻偏移，不能界定在 O(k)。

正确的增量结构是 **前缀复用 O(f) + 后缀重传播 O(n−f) = O(n)/候选**。

### Q3. 有没有被迫发明的新机制？

**没有。** 三个候选全部判否（论证见 `TW_MECHANISM.md`）：

| 候选 | 被迫？ | 新颖？ |
|---|---|---|
| A 时间窗前向推演 | 是（正确性硬门槛） | ❌ Solomon 1987 起的定义式 |
| B 增量校验修复（前缀+后缀传播） | 是（否则算错） | ❌ Savelsbergh 1992 前向时间松弛 |
| C 目标函数含悬停项 | 是（否则次优/死锁） | ❌ 能耗 VRPTW 常规做法 |

C 最接近"有价值"，但最终判否，因为：① "ΣEED 贪心会死锁（4/8、4/6、6/8 点）"
是**我的启发式对目标敏感**的实测结果，带完整可行性回溯的求解器与目标函数无关，
不构成不可能性定理；② "把假设引入的项加进目标函数"是该假设的**直接推论**，
属必然结论而非发明。**如实说：只是"多加了一个约束判断"，没有新机制。**

### Q4. 效果量化（时间窗感知解 vs 忽略时间窗解）

| 指标 | 时间窗感知 | 忽略时间窗 (MVP) |
|---|---|---|
| **① 时间窗可行率** | **7/7 = 100%** | **2/7 = 28.6%**（5 例迟到 2~10 点） |
| **② 总能耗** | — | 不可比（不可行解无有效能耗）；基线可行的 2 例上 TW 持平或更低 |
| **③ 悬停耗电占比** | 1.9% ~ 76.6% | 2.8% ~ 91.9%；3 个 Solomon 子集上**系统性高 12.4~22.4 个百分点** |

### 意外发现（V1 数据的结构性问题）

`tw_solomon_{r101,c101,rc101}_n20.json` 在**单机 + 服务时长**下**不存在可行哈密顿回路**：
仅服务时长之和就超出时间轴跨度（R101 200s>171s、C101 1800s>967s、RC101 200s>179s，
构造性下界 `Σs_i ≤ max l_i` 被违反）。这三个实例是**为车队**（C101 为 25 辆车）
设计的 VRPTW，不适合单机实验。V2/V3 因此改在"最大可行子集"与自建可行实例上进行。

**这条事实同时提示：时间窗与"单机"边界天然冲突** —— 要让它现实，就得引入
多机（VRPTW），而那离 MVP 更远、在先技术更拥挤。
