## 1. 恒等式与等价关系：已被公开（最关键）

我们在 2026-09-10 推导的
$E=\alpha\cdot D_{\text{total}}+\beta\cdot\sum_i q_iD_i$
（见 `WMLP_INSIGHT.md`），经核查**早已被公开**：

| 出处 | 内容 | 年份 |
|---|---|---|
| **Kara, Kara & Yetis, EMVRP** (LNCS 4616:62–71) | 弧代价 = (载重 + 自重) × 距离。我们的式子即其 β 缩放版 | **2007** |
| **Kara et al., Cumulative VRP** (InTech) | 目标为"载重流 × 距离"，且明言 EMVRP ⊂ Cum-VRP ⊃ {MLP, m-TRP} | **2008** |
| **Nagasaki & Takei** (RIMS Kôkyûroku 1691:65–71) | **逐字给出**："单车辆且自重为 0 时，EMVRP 退化为 WMLP" —— 即我们"WMLP + 总距离项"的发现 | **2010** |
| Bianco, Mingozzi & Ricciardelli, CTSP (*Networks* 23(2)) | 累积代价 TSP；DP + 支配规则，精确解至 35 城市 | **1993** |

即：**我们推导的"新"恒等式与等价关系，是 EMVRP 的定义式本身，且"EMVRP = WMLP + 自重项"早在 2010 年就被明确写出。**

## 3. 最后一条可能的空间也不成立

文献代理认为唯一可能的增量是"容量 + 电量**双资源联合支配剪枝**"。但**对本项目的建模不成立**：

- 电量是真实资源维（逐段递减，可绑定）；
- **载重上限不是资源维**：出发载重 = 尚未投递需求之和，**单调递减**，
  故只要总需求 ≤ 载重上限（一次预检），后续各段自动满足。
  因此不存在"双资源 Pareto 支配"问题。

→ 该方向对本建模**为空**。

## 4. 结论与处置建议

**结论：本项目在数学与算法层面已无新颖性空间。** 本问题类已有 PTAS（Sitters 2021）、
3.59-近似（Goemans & Kleinberg）、精确 branch-cut-and-price（Lysgaard & Wøhlk 2014）与系统综述
（*Computers & Industrial Engineering* 169, 2022）。

**不可主张**（写入交底书必被引证驳回）：
- 恒等式 / 等效距离变换 / 与 WMLP 的等价
- 载重-能耗线性模型
- 增量校验
- Held-Karp 式精确 DP 与标签支配

**本项目实际拥有的（工程与评测层面）**：
1. 一套**完整、可复现、经测试**的实现（Python 214 例 + Rust 109 例测试全绿；
   W9 后 Python 侧增至 **267 例**）；
2. **修正后的评测口径**：带电池约束的**真实最优**基线（此前从未算出），
   实测本方法**65.2% 的实例命中精确最优、97.1% 距最优 ≤2%**；
3. 时间窗-悬停方向的**否定性结论**（V1–V3，可复现）；
4. 一份**诚实、数据可溯源**的交底书。

**建议处置**（按优先级）：
1. **交付物定位从"新方法专利"调整为"特定场景的实现与评测"**；
2. 交底书**主动引用并承认**上述已知技术（被引证打掉比自认更伤），
   把主张为空的段落（§5.2 的"变换"、§5.4 的"增量"、附录 1）改写为
   "采用已知模型 + 本场景的实现与实测"；
3. 若仍希望产出学术成果，方向应是**双约束（容量+电量+时间）精确求解的定量研究**，
   需与标准标签支配做严格对比实验——但这是**新的研究课题**，
   且本问题类已有 PTAS，产出高影响力结果的不确定性大。
